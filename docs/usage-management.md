# 模型用量统计

观因企业版在“治理 → 用量统计”提供模型调用的汇总与明细。仅平台管理员可以查看和导出，License 无效时控制面不会接受用量上报或提供查询。

## 统计口径

- 可按用户、空间、模型、租户汇总，也可查看每次实际模型调用的明细。
- 记录调用时间、用户、空间、租户、会话、提供方、模型、输入/输出/总 Token、缓存读写 Token、耗时和成功、失败或取消状态。
- 不保存提示词、回答正文、API Key 或模型密钥。上游未提供 usage 或全部为零时显示“未知”，不会按零估算。
- 缓存读取属于输入 Token 的一部分，不会重复累加。辅助模型调用、多轮调用和重试均按实际流分别计入。
- 无法从可信网关身份关联用户的调用显示为“未归属”，仍计入空间、模型和租户。

## 采集与保留

空间运行时在调用完成后将事件先写入自身 PVC，每 15 秒使用空间专属 `DSH_EXT_TOKEN` 向企业控制面上报；网络异常时保留并重试。控制面按空间与事件 UUID 去重。

用量明细与审计日志均只保留最近一年。控制面启动时和之后每小时永久清理超期记录；升级前如需更长时间留档，应先由数据库备份或外部归档系统保存。

新建空间自动获得企业内部的上报地址。控制面 Service 在集群内通过 `18080` 端口转发至应用的 `8080` 端口；外部管理入口保持原有端口。已有空间需升级至 `bankops/guanyin-enterprise-dsh:0.1.5-rc.2-gy.ent.7`，控制面和 DSH 必须同时升级；历史调用不会补录。休眠空间不需要唤醒，后续启动时会完成运行时配置迁移。

## 验收

1. 平台管理员进入“治理 → 用量统计”，完成一次模型调用后约 15 秒刷新，确认用户、空间、模型和时间正确。
2. 普通成员与租户管理员访问 `/api/admin/usage` 应返回 403；License 无效时应返回授权错误。
3. 切换用户、空间、模型、租户和调用明细维度，确认分页、导出和未知用量显示正常。
4. 检查空间原有模型、MCP、工作区与会话功能保持可用。
