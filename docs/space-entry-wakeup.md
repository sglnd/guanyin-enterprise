# 休眠空间的进入处理

2026-10-27 本地 0.2.1 空间因空闲 120 分钟自动休眠，Deployment 副本为 0。
用户从尚未刷新状态的管理员入口进入时，旧接口返回“实例尚未就绪”。

- 管理员代入访问先重新核对实际状态；休眠空间唤醒并返回 202，启动中的空间返回等待提示。
- 前端只在返回有效 location 时跳转；202 时提示并刷新空间列表，继续轮询启动状态。
- 仅在运行中才授予管理员访问并写入代入访问审计；唤醒操作单独记为启动审计。
- 启动刷新 last_active_at，使休眠前的空闲时间不再导致刚启动的空间立即休眠。
- 管理员鉴权、原有镜像、空间数据和空闲规则保持原有配置。
