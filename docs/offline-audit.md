# 审计使用说明

本版仅保留三类审计，保留期为一年：

- 用户登录。
- 用户聊天输入：保存本次发送的原始文字，关联用户、空间、会话和时间。
- 删除会话：保存操作者、空间、会话、时间和结果。

管理员在“审计与合规”中按用户、空间筛选。在“用户聊天输入”记录内展开
“查看用户输入”即可查看原文；用户管理中的审计弹窗也支持查看。

聊天不新增上下文、AI 回复、推理过程、工具调用、执行结果或附件正文记录。
刷新页面、查看信息、打开删除弹窗和取消删除不记审计。
审计保存在平台数据库，删除空间内会话不会删除审计中的用户输入。

输入审计保存成功后才转发消息；若提示“消息尚未发送”，说明没有交给 AI 执行。
删除审计首次保存失败时，不会提交删除。删除结果可能显示成功、失败、
结果待确认或结果未确认；遇到未确认状态，请刷新实际会话列表核对，不要盲目重复删除。

升级后新提交的消息开始留痕，不补录旧会话。历史杂项审计不再展示或计入分页，
原有数据仍按一年到期规则清理。

记录覆盖经过观因平台的聊天和页面删除请求；直接访问空间接口或从操作系统删除文件
不在本次记录范围。生产入口应只暴露观因控制台，空间 Service 保持集群内访问。
